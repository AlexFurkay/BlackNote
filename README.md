# BlackNote

Тёмный текстовый редактор для Windows в духе классического Блокнота: то же меню
(Файл, Правка, Формат, Вид, Справка), те же сочетания клавиш, ничего лишнего.
Добавлены две вкладки — **Советы** (разметка Markdown как на GitHub) и **Цвета** — и вертикальное выделение.

Автор: **AKFRK**.

*A dark, Notepad-style text editor for Windows with column selection and GitHub-flavoured Markdown.*

## Возможности

- **Как Блокнот:** Создать / Открыть / Сохранить, Найти, Заменить, Перейти, Время и дата (F5),
  перенос по словам, шрифт, масштаб, строка состояния, печать, вопрос «Сохранить изменения?».
- **Полностью тёмный:** меню, заголовок окна, полосы прокрутки, диалоги.
- **Вертикальное выделение:** зажми **Alt** и веди мышью, затем печатай — текст появится сразу во всех строках.
  С клавиатуры — **Alt + Shift + стрелки**. **Ctrl + клик** добавляет ещё один курсор.
- **Вкладка «Советы» — Markdown как на GitHub:**
  - подсветка разметки прямо в тексте;
  - все команды: жирный, курсив, зачёркнутый, код, заголовки, списки, задачи, цитаты, блоки кода,
    ссылки, картинки, таблицы, линии, спойлеры (по желанию — панель кнопок под меню);
  - шпаргалка со всеми командами (**F1**);
  - предпросмотр «как на GitHub» (**Ctrl+Shift+V**).
- **Вкладка «Цвета»:** свой цвет текста и фона или готовые схемы (тёмная, чёрная, графит, сепия, ночная синяя, терминал, светлая).
- **Кодировки:** UTF-8, UTF-8 с BOM, UTF-16 LE/BE, ANSI; концы строк Windows / Unix / Mac — определяются сами,
  как в Блокноте.
- Многоуровневая отмена (Ctrl+Z / Ctrl+Y).

## Сочетания клавиш Markdown

| Команда | Клавиши |
| --- | --- |
| Жирный / курсив / зачёркнутый | Ctrl+B / Ctrl+I / Ctrl+Shift+X |
| Код в строке / блок кода | Ctrl+\` / Ctrl+Shift+\` |
| Заголовок 1–3 | Ctrl+1 … Ctrl+3 |
| Список / нумерованный / задачи | Ctrl+Shift+8 / 7 / 9 |
| Цитата | Ctrl+Shift+Q |
| Ссылка / картинка | Ctrl+K / Ctrl+Shift+K |
| Таблица / линия / спойлер | Ctrl+Shift+T / H / D |

## Сборка

Нужен [.NET 8 SDK](https://dotnet.microsoft.com/download).

```
cd src
dotnet build -c Release
```

Готовая программа — `src\bin\Release\net8.0-windows\win-x64\BlackNote.exe`.
Для запуска нужен .NET 8 Desktop Runtime (Windows 10 / 11, x64).

Самопроверка разработчика: `BlackNote.exe --selftest <папка>` — откроет окно с примером, сохранит снимки
и результаты проверок команд в указанную папку. Настройки пользователя при этом не меняются.

Иконка рисуется скриптом `tools\make-icon.ps1`.
